# hiccai-xhs

小红书爆款运营 Skill，用于生成、改写、审核小红书标题、封面标题、Hook、图文笔记、短视频脚本、话题标签、评论引导、账号选题和内容策略。

这个仓库里的核心文件是 [`xhs/SKILL.md`](xhs/SKILL.md)。它把「小红书网感」拆成可执行流程：先判断选题和人群，再设计标题、封面、Hook、正文、收藏点、评论区和搜索关键词。

## 适用场景

- 小红书标题库、封面标题、开头 Hook
- 探店、种草、本地生活、旅游、活动推广
- 美妆、穿搭、母婴、家居、餐饮、酒店
- 商业地产、品牌内容、产品推广
- 原稿优化、爆款审核、评论区设计
- 账号定位、选题策划、内容策略

## 核心能力

- **选题重构**：把普通素材改成更有点击理由的小红书角度。
- **标题生成**：按反差、避坑、嘴替、情绪、信息差、搜索等方向批量输出。
- **封面停顿感**：输出 6-14 字的短封面标题，避免广告腔。
- **Hook 设计**：生成反差版、嘴替版、避坑版、情绪版、结果版开头。
- **完整笔记**：包含选题、人群、标题、封面、Hook、正文、图片建议、收藏点、评论引导、搜索词和标签。
- **改稿诊断**：先指出原稿问题，再给可发布版本。
- **爆款审核**：按选题、标题、封面、Hook、正文、收藏、评论、搜索打分。
- **真实性边界**：素材不足时使用占位或提醒补充，不编造价格、地址、体验和效果。

## 安装方式

复制 `xhs` 目录到 Codex skills 目录：

```bash
cp -R xhs ~/.codex/skills/xhs
```

安装后，在 Codex 里可以直接用类似提示触发：

```text
用 xhs 帮我写一篇杭州咖啡馆探店笔记
```

```text
这个标题太官方了，帮我改成20个小红书爆款标题：
城市美学空间焕新启幕
```

```text
帮我审核这篇小红书笔记能不能爆，并给重写版本
```

## 质量原则

这个 Skill 会优先避免以下问题：

- 官方宣传腔：如「隆重开启」「焕新升级」「高品质生活方式」
- 空泛形容：只说「好玩」「高级」「治愈」「出片」，但没有具体理由
- 假爆款词堆砌：如「救命」「绝了」「封神」「狠狠爱了」
- 写给所有人：没有明确人群和场景
- 没有收藏点：缺少路线、清单、价格、步骤、避坑或适配判断
- 编造体验：素材不足时硬写真实经历、价格、地址或效果

主要改进：

- 重构为「路由 → 洞察 → 生成 → 自检」流程。
- 增加素材不足 fallback 和真实性边界。
- 补齐标题、封面、Hook、完整笔记、短视频、改稿、审核等输出模板。

## 说明

小红书爆款不能被任何工具保证。这个 Skill 的目标是提高内容质量和爆款概率：让内容更像真人、更有判断、更有收藏价值、更容易被评论，也更适合搜索流量。
