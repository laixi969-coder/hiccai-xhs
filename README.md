# hiccai-xhs

小红书爆款内容操盘 Skill，用于生成、改写、审核小红书标题、封面标题、Hook、图文笔记、短视频脚本、话题标签、评论引导、账号选题、账号栏目和发布策略。

这个仓库里的核心文件是 [`hiccai-xhs/SKILL.md`](hiccai-xhs/SKILL.md)。它把「小红书网感」拆成可执行流程：先重构选题和用户关系，再设计标题、封面、Hook、正文、收藏点、评论区、搜索关键词和账号策略。

## 适用场景

- 小红书标题库、封面标题、开头 Hook
- 探店、种草、本地生活、旅游、活动推广
- 美妆、穿搭、母婴、家居、餐饮、酒店
- 商业地产、品牌内容、产品推广
- 原稿优化、爆款审核、评论区设计
- 账号定位、选题策划、内容策略

## 核心能力

- **选题重构**：把普通素材改成更有点击理由的小红书角度。
- **五力模型**：围绕停手力、点击力、完读力、收藏力、互动力优化内容。
- **七愿意闸门**：输出前检查用户是否愿意停、点、看、存、评、转、关注。
- **标题生成**：按反差、避坑、嘴替、情绪、信息差、搜索等方向批量输出。
- **封面停顿感**：输出 6-14 字的短封面标题，避免广告腔。
- **Hook 设计**：生成反差版、嘴替版、避坑版、情绪版、结果版开头。
- **完整笔记**：包含选题、人群、标题、封面、Hook、正文、图片建议、收藏点、评论引导、搜索词和标签。
- **改稿诊断**：先指出原稿问题，再给可发布版本。
- **爆款审核**：按选题、标题、封面、Hook、正文、收藏、评论、搜索打分。
- **真实性边界**：素材不足时使用占位或提醒补充，不编造价格、地址、体验和效果。
- **商业安全边界**：自动降噪绝对化功效、收益承诺、虚假背书和未核实对比。

## 如何安装

#### 通用安装方式

```bash
npx -y skills add laixi969-coder/hiccai-xhs -g --all
```

#### 手动安装

复制 `hiccai-xhs` 目录到 Codex skills 目录：

```bash
cp -R hiccai-xhs ~/.codex/skills/hiccai-xhs
```

#### 从 Release 安装

如果你使用支持上传 skill zip 的工具，可以从 GitHub Releases 下载 `hiccai-xhs-版本号.zip`。zip 解压后根级是 `SKILL.md`。

## 如何更新

通过 `npx skills add` 安装的用户，重新运行一次同样的命令即可：


手动安装的用户，重新复制 `hiccai-xhs` 目录即可：


## 工作流地图

```text
素材/想法
    ↓
判断任务类型
    ↓
提炼目标人群和使用场景
    ↓
重构选题角度
    ↓
标题 / 封面 / Hook
    ↓
正文结构 + 收藏点 + 避坑判断
    ↓
评论引导 + 搜索关键词 + 标签
    ↓
发布前自检
```

### 内容局部优化

```text
标题无感 → 标题模式
封面不抓人 → 封面模式
开头太慢 → Hook 模式
正文像广告 → 改稿模式
不知道能不能发 → 审核模式
只有粗糙素材 → 完整图文笔记
```

### 标题生成逻辑

标题模式会标注每条标题的「公式/触发器」，避免只凭感觉生成。

当前内置公式包括：

- `XHS-T01`：人群 + 痛点 + 解决方案
- `XHS-T02`：反差 + 结果
- `XHS-T03`：情绪 + 场景
- `XHS-T04`：提醒 + 避坑
- `XHS-T05`：疑问 + 好奇
- `XHS-T06`：真实体验 + 反转
- `XHS-T07`：嘴替 + 共鸣
- `XHS-T08`：搜索词 + 网感
- `XHS-T09`：数字 + 收藏理由
- `XHS-T10`：争议判断 + 适配人群

## 质量原则

这个 Skill 会优先避免以下问题：

- 官方宣传腔：如「隆重开启」「焕新升级」「高品质生活方式」
- 空泛形容：只说「好玩」「高级」「治愈」「出片」，但没有具体理由
- 假爆款词堆砌：如「救命」「绝了」「封神」「狠狠爱了」
- 写给所有人：没有明确人群和场景
- 没有收藏点：缺少路线、清单、价格、步骤、避坑或适配判断
- 编造体验：素材不足时硬写真实经历、价格、地址或效果
- 高风险商业表达：如「一定有效」「7 天见效」「全网最安全」「保证涨粉」

- 本轮新增「七愿意输出闸门」，完整笔记和短视频输出必须说明停、点、看、存、评、转、关注的设计。

## 本地打包

仓库内置一个轻量打包脚本，会把 `hiccai-xhs/SKILL.md` 和 `hiccai-xhs/test-prompts.json` 打成可上传的 skill zip：

```bash
bash tools/build-skill.sh
```

产物位置：

```text
dist/skills/hiccai-xhs-版本号.zip
```

版本号来自 [`VERSION`](VERSION)。推送 `v版本号` tag 时，GitHub Actions 会自动构建并发布 Release。

## 说明

小红书爆款不能被任何工具保证。这个 Skill 的目标是提高内容质量和爆款概率：让内容更像真人、更有判断、更有收藏价值、更容易被评论，也更适合搜索流量。
